# Amazon ML Challenge: Business Entity Resolution

This repository contains the end-to-end competition codebase for the **Business Entity Resolution** task, implementing the **Calibrated Precision-First Cascade (CPFC)**.

## Quick Commands

```bash
# 1. Run complete test suite (21 unit tests across all components)
make test

# 2. Generate benchmark synthetic dataset
make data

# 3. Execute the full CPFC training and inference cascade
make run

# 4. Validate output submission files against official constraints
make validate

# 5. Package for submission
make package
```

Refer to [Documentation_template.md](Documentation_template.md) and [code/business_entity_resolution/README.md](code/business_entity_resolution/README.md) for full architecture and technical documentation.
